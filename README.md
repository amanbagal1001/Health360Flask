## 🌟 Overview

**Health360** brings key patient risk factors, disease indicators, and lifestyle patterns together in one place. It delivers an intuitive, interactive analytics experience designed to help viewers explore healthcare data, compare age demographics, and understand health trends.

### ✨ Key Features

- **Interactive Tableau Dashboard:** Live embedded dashboard exploring BMI categories, diabetes, heart disease, stroke, and other clinical indicators.
- **Data Storytelling:** Guided Tableau Story walkthrough covering patient demographics, fatigue condition, physical activity levels, and blood pressure.
- **Modern Responsive Web UI:** Designed with modern aesthetics, custom typography, smooth transitions, mobile navigation, and interactive feature cards.
- **Dual Execution Mode:** Runs as a full Flask web application or can be opened directly as standalone HTML with offline styles.
- **Detailed Project Report:** Complete project documentation and analytics report included as PDF.

## 🚀 Quick Start Guide

### Option 1: One-Click Run (Windows)
Simply double-click **`run.bat`** in the project folder. It will launch the Flask server and automatically open the website in your default browser.

### Option 2: Running via Terminal

1. **Clone the repository:**
   ```bash
   git clone https://github.com/amanbagal1001/Health360Flask.git
   cd Health360Flask
   ```

2. **(Recommended) Create and activate a virtual environment:**
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Flask application:**
   ```bash
   python app.py
   ```

5. **Open in your browser:**  
   Navigate to [http://127.0.0.1:5000](http://127.0.0.1:5000)
