# Health360 Flask Website

## Run on Windows
1. Extract this ZIP and open the folder in VS Code.
2. Open Terminal.
3. Run:
   ```bash
   python -m venv venv
   venv\\Scripts\\activate
   pip install -r requirements.txt
   python app.py
   ```
4. Open http://127.0.0.1:5000

Pages: Home `/`, About `/about`, Dashboard `/dashboard`, Story `/story`, FAQ `/faq`.

Dashboard and Story embed your Tableau Public views. Internet access is required.
